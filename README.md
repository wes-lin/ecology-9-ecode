# ecode-dev-assistant

A monorepo for local development assistant for 泛微 Ecology 9 ecode.

## Packages

- `packages/ecode-sdk` — JavaScript SDK for ecode API (login, upload, download, tree).
- `packages/vscode-ecode` — VS Code extension that uses `ecode-sdk` to browse and download ecode files.

## Development

```bash
npm install
npm run build
```
