# 更新日志（Changelog）

**Weaver Ecology eCode** 扩展的所有重要变更记录在此文件中。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本管理遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## 0.1.5 - 2026-09-08

### 修复

- 本地调试：会话**处于启动中（starting）时也能执行「停止」和「重启」**。启动中的会话通过 `ecode.dev.starting` 状态跟踪，新的启动/重启前会先取消仍在进行中的启动流程；被取消的操作不再弹出误导性的“已运行”成功提示或报错通知。
- 启动过程中执行「停止」/「重启」不再残留孤儿代理进程或错误的 `ecode.dev.running` 状态。

### 变更

- 开发服务器输出日志改为显示**本地时间（含时区偏移）**，替代原来的 UTC 时间，便于与 IDE 及系统日志对应排查。
- 热重建引擎（`ecode-dev-runtime`）稳定性与响应性提升：
  - 重建任务**防抖（debounce）并串行排队**，过期的排队重建会被丢弃，重建调度可通过 `AbortSignal` 取消。
  - 构建调度在**编译步骤之间让出事件循环**，大型 JS 应用构建不再阻塞扩展宿主与文件监听。
  - 应用 JS 与预置（pre-state）CSS 的重新编译改为**有界并发池**执行，取代原先无限制的 `Promise.all`。
  - 重建开始时**立即使上一份构建状态失效**，避免因停止/重启而中断或覆盖的构建从过期状态继续恢复。
- 构建状态元数据改用**文件内容哈希（SHA-256）**快照，替代原有“大小 + mtime”的变更检测，判断更准确。
- 生成的 App 配置文件（`appConfig-*.json`）仅在**内容真正变化时才写盘**，避免无谓触发文件监听与重建循环。
- 本地调试代理现在会**隔离上游连接**与浏览器 keep-alive：请求与响应两方向都会**剥离逐跳（hop-by-hop）头**（`Connection`、`Keep-Alive`、`TE`、`Trailer`、`Transfer-Encoding`、`Upgrade`、`Proxy-*` 等），且上游连接不复用。
- 代理请求失败时输出**结构化错误信息**（请求方法、目标、路径、解析错误 `code`/`reason`/`bytesParsed`），当上游返回非法 HTTP 响应时附带可操作的排查提示；响应中途失败或客户端中断时干净地释放连接，避免向已关闭的响应中继续写入。

### 新增

- 新增开发会话管理器、开发代理与开发运行时的自动化测试，覆盖：会话启动/取消、代理逐跳头剥离、上游非法 HTTP 响应、重建调度/取消、有界并发构建等场景。

### 变更

## 0.1.3 - 2026-09-02

### 新增

- 支持从本地文件的远程对比结果中直接编辑远端文件。

## 0.1.2 - 2026-09-01

### 变更

- 本地开发时避免不必要的 eCode 重复重建，开发反馈更及时。

## 0.1.1 - 2026-08-31

### 修复

- 允许 eCode 环境地址解析为 `localhost`，无需自定义域名映射即可搭建本地调试环境。

## 0.1.0 - 2026-08-31

### 新增

- **Weaver Ecology eCode** 首个应用市场正式版本。
- 本地 eCode 开发运行时：源码变更实时重建，并可通过本地反向代理在浏览器中预览。
- 远端 eCode 目录树浏览、在线文件编辑、快照管理与发布/升级工作流。
- 中英文双语文档与应用市场元数据。
