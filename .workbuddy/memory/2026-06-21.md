# 2026-06-21

- 初始化 ecology-9-ecode monorepo 基础架构：
  - 根目录 `package.json` 配置 npm workspaces，包含 `packages/*`。
  - 创建 `packages/ecode-sdk`：提供登录、文件树、上传、下载的 JavaScript SDK（CommonJS）。
  - 创建 `packages/vscode-ecode`：VS Code 插件，依赖 `ecode-sdk`，在 Explorer 中展示 ecode 目录/文件树，支持下载文件到本地配置目录（默认 `src`）。
  - 配置项：`ecode.baseUrl`、`ecode.username`、`ecode.password`、`ecode.localDir`。
  - 运行 `npm install` 和 `npm test --workspace=ecode-sdk` 通过测试。
- 将 `ecode-sdk` 的 `src/http-client.js` 从 Node.js 内置 `http`/`https` 模块迁移到现代全局 `fetch` API，普通 POST body 使用 `URLSearchParams` 序列化，上传仍使用 `form-data`。
- 合并 `ecode-sdk` 架构：将 `http-client.js` 和 `api.js` 的职责并入 `client.js`，删除 `api.js` 和 `http-client.js`，简化对外导出为单一 `EcodeClient`。
- 改进 `vscode-ecode` 插件：
  - `treeDataProvider` 在未配置 `ecode.baseUrl` / `username` / `password` 时显示提示节点，配置错误或登录失败时显示错误信息节点，方便用户排查。
  - 命令标题改为 `eCode: Refresh Explorer` 和 `eCode: Download File`，方便在命令面板中搜索。
- 移除 `vscode-ecode` 的 `activationEvents` 字段，VS Code 1.75+ 会自动根据 `contributes.views` / `commands` 推断激活时机。
