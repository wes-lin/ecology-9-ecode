# eCode 扩展可见性、设置页与 Cookie 会话

## VS Code 扩展可见性调试

- 调试 `vscode-ecode` 插件在 VS Code 中不可见的问题。
- 更新 `.vscode/launch.json`，提供两种启动配置：
  - `Run Extension (monorepo root)`
  - `Run Extension (package folder)`
- 在 `extension.js` 新增 `ecode.openSettings` 命令。
- 在 `package.json` 注册设置命令，并在 `eCode Explorer` 视图标题栏添加设置按钮。
- 明确调试方式：必须按 `F5` 启动 Extension Host，并在 Extension Host 中打开文件夹，才能看到 `eCode Explorer` 视图。

## Activity Bar 与 Settings Webview

- 将 `eCode Explorer` 从 Explorer 侧栏内部视图改为独立 Activity Bar 容器。
- 添加 `media/ecode.svg` 图标，左侧活动栏显示 eCode 图标。
- 将 eCode 活动栏面板拆分为上下两部分：
  - `Settings`：使用 Webview View 显示配置表单。
  - `Explorer`：显示 ecode 目录树。
- 新增 `src/settingsWebviewProvider.js`。
- 删除旧的 `src/settingsProvider.js`。
- Settings 表单支持一次性修改：
  - Server
  - Account
  - Password
  - Local Dir
- 保存后自动刷新 Explorer 视图。
- 修复 Webview View 注册错误：在 `package.json` 的 `views` 中为 `ecodeSettings` 添加 `type: webview`，避免 VS Code 将其当作普通树视图并要求 data provider。
- 为 Settings Webview 表单参数添加图标：Server、Account、Password、Local Dir，并为保存按钮添加图标。

## 工程格式化与编辑器配置

- 根目录添加 `eslint.config.js`，使用 ESLint 9 flat config。
- 引入 `@eslint/js` 和 `eslint-config-prettier`。
- 添加 `.prettierrc`：
  - 单引号
  - 120 列宽
  - 2 空格缩进
- 添加 `.vscode/settings.json`，配置保存时自动 Prettier 格式化与 ESLint 自动修复。
- 添加 `jsconfig.json`，为 `ecode-sdk` 提供路径别名提示，支持 VS Code JavaScript 智能提示。
- 修复 `packages/vscode-ecode/package.json` 中 Activity Bar 图标路径错误。
- 为 `vscode-ecode` 补充空的 `test` 脚本，使 `npm test --workspaces` 可正常运行。

## Cookie 会话管理

- 将 `ecode-sdk` 改为基于 Cookie 的会话管理。
- 新增 `CookieJar` 类：
  - 自动解析 `Set-Cookie`
  - 后续请求自动携带 `Cookie` 头
- `login()` 后从响应头提取 Cookie 存入 Jar，后续请求不再显式传 session。
- 新增 `CookieJar` 单元测试。
- 实现 Cookie 持久化：
  - `CookieJar.loadFromFile()`
  - `CookieJar.saveToFile()`
- `EcodeClient` 构造函数新增 `cookieFile` 选项。
- SDK 初始化时自动加载已有 Cookie，登录成功后自动保存。
- 新增 `isLoggedIn()` 和 `logout()` 方法。
- VS Code 扩展通过 `context.globalStorageUri` 指定 Cookie 文件路径：`cookies.json`。
- `treeDataProvider` 在刷新 / 下载前检查 `isLoggedIn()`，仅在没有有效 Cookie 时调用登录接口。
