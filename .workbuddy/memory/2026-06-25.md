# eCode VS Code 扩展：本地编辑、远程对比与整树下载

## 本地编辑与远程对比

- 新增本地编辑工作流。
- 文件节点默认打开本地真实文件，而不是只读 `ecode:` 虚拟文档。
- 本地文件路径规则：`${workspaceFolder}/${ecode.localDir}/${remotePath}`。
- 本地文件不存在时，使用 `client.viewFile(element.id)` 从远程初始化内容。
- 本地文件已存在时不覆盖，避免破坏用户本地修改。
- 新增 `ecode.compareWithRemote`。
- compare 行为：每次对比都实时拉取远程最新内容。
- 对比方式：
  - 左侧：远程最新只读 `ecode:` 快照。
  - 右侧：本地真实文件。
- 保留 `ecode.viewFile` 作为只读远程预览能力。
- 修复 `EcodeClient.downloadFile()`：返回 `Buffer`，不再返回 raw `Response`。

## 下载命令简化

- 删除 VS Code 命令 `ecode.downloadFile`。
- 将 `ecode.downloadSelected` 改为 `ecode.download`。
- 移除 checkbox 选择逻辑、checkbox 状态监听和节点 checkbox 显示。
- `ecode.download()` 当时先保留为占位提示：`Download is not implemented yet.`。
- 保留 SDK 底层 `client.downloadFile()`，仅不再作为 VS Code 命令暴露。

## 文件夹刷新

- 新增文件夹右键命令 `ecode.refreshFolder`。
- 刷新时删除该节点缓存的 `children`，并触发该文件夹节点重新加载。
- 刷新按钮只出现在文件夹右键菜单中，不作为 inline 小按钮显示。
- 修复可删除文件夹 `contextValue` 变为 `folder-deletable` 后刷新菜单消失的问题。
- 右键菜单条件改为包含判断：`viewItem =~ /folder/`，因此 `folder` 和 `folder-deletable` 都会显示刷新。

## 预发布状态标识

- `EcodeNode` 新增 `state` 字段，用于接收远程返回的 `item.state`。
- 当 `state === 'pre-state'` 时，在树节点右侧显示 `P` 标识。
- 当前使用 `treeItem.description = 'P'` 实现，简单显示在列表文字右侧。

## 删除命令入口

- 文件和文件夹右键新增 `ecode.deleteItem`。
- 节点使用 `deletable` 字段决定是否显示删除菜单。
- 当时的 `contextValue` 规则：
  - 普通文件：`file`
  - 普通文件夹：`folder`
  - 可删除文件：`file-deletable`
  - 可删除文件夹：`folder-deletable`
- 删除前会弹窗确认。
- 非 `deletable` 节点即使命令误触也会阻止。
- 实际删除 API 尚未实现，确认后只提示 `Delete is not implemented yet.`。
- 右键菜单条件改为包含判断：`viewItem =~ /deletable/`。
- 文件操作菜单条件改为 `viewItem =~ /file/`，因此 `file-deletable` 也会显示打开本地、远程对比、只读查看等文件命令。

## ecode 源码整树下载

- 实现 `ecode.download`，不再是占位提示。
- 下载范围：从远程 ecode 根文件树开始整树遍历，不依赖 VS Code 树节点是否已经展开。
- 遍历规则复用现有树加载逻辑：
  - 根节点调用 `client.listTree()`。
  - `treeType === 'folder'` 的节点用 `folderId` 加载子节点。
  - 其他可展开类型用 `typeId` 加载子节点。
- 文件夹处理：遇到 folder 节点时，使用本地安全路径创建对应目录。
- 文件处理：遇到 file 节点时，复用 `_ensureLocalFileFromRemote(element, { overwrite: true })`。
- 本地路径统一经过 `_getLocalPath()` / `_getSafeRelativeRemotePath()`，保留路径穿越防护。
- 下载进度使用 `vscode.window.withProgress` 显示通知进度。
- 进度策略：先扫描远程树收集 folders / files，得到总文件数后按 `Downloaded x/y` 递增展示。
- 当前下载采用顺序执行，避免并发请求压垮 ecode 服务或带来写入竞态。
- 下载完成后提示 `eCode source download completed.`。
- 失败时提示 `Download failed: ...`。

## eCode Explorer 下载期间禁用

- 新增 provider busy 状态 `_busy`。
- 新增 VS Code context key：`ecodeExplorer.busy`。
- 扩展激活时初始化 `ecodeExplorer.busy = false`。
- 下载开始时设置 busy，下载成功或失败后在 `finally` 中恢复。
- `package.json` 中 eCode Explorer 相关命令增加 `enablement: "!ecodeExplorer.busy"`。
- 标题栏和节点菜单 `when` 条件追加 `!ecodeExplorer.busy`。
- 运行时也加保护：
  - `refresh`
  - `refreshFolder`
  - `openLocalFile`
  - `compareWithRemote`
  - `deleteItem`
  - `viewFile`
- `getChildren()` 在 busy 时不发起新的远程加载，优先返回已有缓存，避免展开节点触发远程请求。

## EcodeNode 构造函数优化

- `EcodeNode` 构造函数从长参数列表改为对象参数。
- 可选字段提供默认值，降低调用时的参数顺序风险。
- info 节点和 `_mapTree()` 中的节点创建都改为命名字段形式。
