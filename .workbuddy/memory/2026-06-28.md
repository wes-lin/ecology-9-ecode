# eCode Explorer 命令与预加载配置

## 工作内容

- 整理 `ecodeExplorer` 右键菜单的显示逻辑。
- 将节点菜单条件从直接判断 `file` / `folder` / `deletable`，调整为基于能力标签：
  - `canRefreshFolder`
  - `canDelete`
  - `canCompare`
  - `canViewRemote`
  - `canRelease`
  - `canCancelRelease`
  - `canSetPreload`
  - `canCancelPreload`
  - `canSetPreloadOrder`
- 在 `EcodeTreeDataProvider._getContextValue()` 中集中生成节点能力，减少 `package.json` 里菜单条件和业务状态的耦合。
- 复用 `_getRemoteUri()` 创建 `ecode:` URI，减少重复字符串拼接。
- 复用 `_listRemoteChildren()` 加载远程子节点，减少 `getChildren()` 中重复的 `client.listTree()` + `_mapTree()` 逻辑。
- 简化 `EcodeNode` 构造函数：类属性提供默认值，constructor 使用 `Object.assign()` 覆盖。
- 新增 `RemoteTreeItem.status` / `RemoteTreeItem.preStateOrder` 映射到：
  - `EcodeNode.appStatus`
  - `EcodeNode.appPreStateOrder`
- 新增 release / cancel release 命令入口，目前为占位实现：
  - `ecode.release`
  - `ecode.cancelRelease`
- 新增文件预加载状态命令入口，目前为占位实现：
  - `ecode.setPreload`
  - `ecode.cancelPreload`
- 新增应用预加载顺序命令入口：
  - `ecode.setPreloadOrder`
  - 仅对带 `appId` 的节点显示
  - 点击后弹出输入框，回显 `appId`、文件夹名称和当前 `appPreStateOrder`
  - 输入值校验为数字
  - 当前仍为占位实现，不调用后端

## Compare with Remote 调整

- 修复 compare 本地侧无法编辑的问题。
- 远程侧继续使用只读 `ecode:` 虚拟文档。
- 本地侧改回真实文件 URI：`vscode.Uri.file(targetPath)`。
- 保留远程侧原始文件扩展名，避免 diff 视图丢失语法高亮。

## 下载后生成应用配置

- `ecode.download()` 在扫描完整远程树后，会在当前工作区根目录生成：
  - `ecode-apps.json`
- 配置内容来源于带 `appId` 的 folder 节点。
- 每个应用配置包含：
  - `path`
  - `appId`
  - `appStatus`
  - `appPreStateOrder`
  - `preStateFiles`
- `preStateFiles` 直接从下载扫描得到的 `nodes.files` 中筛选：
  - `file.state === 'pre-state'`
  - `file.remotePath` 位于该 app 目录下
  - 输出相对 app 目录的路径
- `_collectDownloadNodes()` 在遍历 folder 时会把远程加载到的 children 回填到 `element.children`，方便树数据后续复用。

## 开发构建优化

- `packages/vscode-ecode/esbuild.js` 新增 `--watch` 支持。
- `packages/vscode-ecode/package.json` 新增脚本：
  - `pnpm --filter vscode-ecode watch`
- 开发时可以保持 watch 运行，修改 TypeScript 后自动重建 `dist/extension.js`。
- VS Code Extension Development Host 仍需要 reload 才能加载新的扩展代码或 contributes 配置。

## 注意事项

- VS Code 扩展入口是 `packages/vscode-ecode/dist/extension.js`，不是 `src/extension.ts`，因此修改 TypeScript 后需要重新 build 或保持 watch 运行。
- `package.json` 中的 contributes / menus / commands 修改通常需要重启或 reload Extension Development Host 才会生效。
- 当前 release、cancel release、set preload、cancel preload、set preload order 都只是命令入口和 UI 占位，尚未接入真实 eCode 后端 API。
